# Editable portfolio source

All portfolio content is in `src/data/content.js`.

Run `npm install` once. Use `npm run dev` to develop, or `npm run standalone` to build and update the ready-to-open `index.html` in the parent folder.

The parent HTML file contains the compiled scripts, CSS, and favicon and works directly from the filesystem. Gmail, LinkedIn, and the optional Google Font use internet access.
