SRISHTI VASAN PORTFOLIO

TO VIEW THE WEBSITE
Double-click index.html in this folder. It opens the complete portfolio in your browser.
No installation, terminal, or local server is needed.

FILES
index.html - Ready-to-open website, with its styling, JavaScript, and favicon embedded.
source/    - Editable React project for future changes. You do not need this folder to view the website.

Internet access is needed for Gmail, LinkedIn, and the optional Google Font. The portfolio content and interactions work without internet; an offline font fallback is included.

TO EDIT AND REBUILD
Open source/ in your editor. Run npm install, then npm run standalone.
This builds the project and replaces the index.html in this folder with your changes.
